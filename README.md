# 品川弥二郎発信書簡 所蔵館マップ

## 概要

品川弥二郎が発信した書簡等の所蔵機関を、地図上で確認するためのウェブマップです。

地図上のマーカーを選択すると、所蔵機関名、所在地、所収史料群名、所蔵確認点数、
調査状況などを確認できます。

## 公開内容

このリポジトリでは、研究元データ、CSVファイルおよび地図生成用Pythonコードは公開せず、
閲覧用の地図HTMLを公開しています。

- `index.html`：公開用ウェブマップ
- `README.md`：地図の概要と更新履歴
- `LICENSE`：利用条件

地図の生成に使用した研究元データ、CSVファイルおよびPythonコードは、
本リポジトリとGitHub Releaseの配布物には含まれていません。

## 閲覧方法

GitHub Pagesで公開されている地図へアクセスしてください。

リポジトリから直接確認する場合は、`index.html` をダウンロードしてブラウザで開くこともできます。
地図タイルや表示用ライブラリを外部サービスから読み込むため、閲覧にはインターネット接続が必要です。

## 地図の見方

- マーカーを選択すると、所蔵機関と史料に関する情報が表示されます。
- 地図上の表示位置は、所蔵機関の所在地を示します。
- レイヤー切替を使うと、地域ブロックごとに表示・非表示を変更できます。
- 複数の史料群が同じ機関に所蔵されている場合は、一つのマーカーにまとめて表示されます。

## 利用上の注意

- 掲載情報は調査時点のものです。
- 所蔵状況、施設名、所在地、閲覧条件等は変更される場合があります。
- 実際に史料を閲覧する際は、各所蔵機関の公式情報を確認してください。
- 地図上の位置は、施設の所在地を把握するための目安です。
- 本地図は研究上の調査成果を可視化したものであり、網羅性を保証するものではありません。
